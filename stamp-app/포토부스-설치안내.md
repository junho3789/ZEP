# POST:ME 포토부스 촬영 연출 v1.10

## 다운로드와 업데이트
전체 앱 ZIP: https://github.com/junho3789/ZEP/raw/refs/heads/main/dist/zep-object-stamps-v1.10.zepapp.zip

기존 앱을 삭제하지 말고 위 ZIP으로 업데이트한 뒤 맵에 재접속하세요. !stamp-version으로 1.10-photo-flash를 확인합니다. 제공받은 프로그램 이름·링크 1~3·구글폼·스탬프 ID·이벤트 ID를 유지했습니다. 기존 수집 기록은 동일 이벤트에서 이어집니다.

ZIP에는 main.js, stamp-ui.html, stamp-mini.html, stamp-special.html, stamp-entry.html, photo-booth.html 총 6개 파일이 루트에 있습니다. main.js와 photo-booth.html만 따로 복사하지 말고 전체 ZIP으로 업데이트하는 것을 권장합니다. 이번 연출 중 스탬프 창 숨김·복원에는 stamp-ui.html과 stamp-mini.html도 필요합니다.

## 포토부스 오브젝트 연결
1. 맵 편집기에서 포토존의 카메라 또는 단말기 오브젝트를 선택합니다.
2. 기존 스탬프 오브젝트와 같은 **ZEP Script 상호작용** 기능을 지정합니다.
3. 실행 방법은 **F키**, 실행 범위는 **1**로 지정합니다.
4. 번호는 **206**, 값은 **photo:booth**로 입력하고 맵을 저장합니다.

웹링크 열기 기능이 아닌 ZEP Script 상호작용으로 연결합니다. 기존 201~204번 스탬프와 205번 응모 데스크는 그대로 둡니다. 206번을 이미 다른 용도로 사용한다면 CONFIG.photoBooth.number/value와 맵 오브젝트의 번호/값을 함께 바꾸고 다른 오브젝트와 겹치지 않게 설정하세요.

## 실행 동작
- 상호작용한 이용자의 화면에만 3 → 2 → 1을 1초 간격으로 표시합니다.
- 마지막에 흰색 플래시를 짧게 한 번 표시하고 자동으로 닫습니다.
- 연출 중 스탬프 수집 창과 축소 아이콘을 잠시 숨기며 종료하면 이전 펼침/접힘 상태로 복원합니다.
- 닫기 버튼 또는 Esc로 중간에 종료할 수 있습니다. 배경 클릭은 종료하지 않습니다.
- 실행 중 반복 F 입력은 무시합니다. 완료 후 다시 상호작용하면 재실행합니다.
- 탭을 숨기면 연출을 취소하여 복귀 시 지연된 플래시가 나오지 않게 합니다.
- 로딩/완료 메시지가 유실되면 서버·HTML 타임아웃으로 창을 정리합니다. 닫기 실패 시 닫기 다시 시도 버튼을 표시합니다.
- 이동속도, 아바타 모습, 스탬프 수집 수는 바꾸지 않습니다. 퇴장·앱 종료·관리자 초기화 시 연출도 정리합니다.

**촬영 느낌을 주는 연출 기능입니다. 실제 스크린샷 촬영·아바타 이미지 추출·폴라로이드 카드 생성·이미지 저장은 포함하지 않습니다.**

## 변경 가능한 설정
main.js의 CONFIG.photoBooth:

```js
CONFIG.photoBooth = {
  enabled: true,
  number: '206',
  value: 'photo:booth',
  stepMs: 1000,
  flashMs: 160
};
```

stepMs는 각 숫자의 표시 시간으로 500~2000ms, flashMs는 플래시 시간으로 80~300ms 범위 내에서 적용됩니다. 운영체제의 모션 줄이기 설정에서는 플래시 밝기를 낮춥니다.

## 검증
Node 모의 ZEP 테스트 54개 통과. 신규 기능은 번호·값 일치, 비활성화, 중복 입력, 타인·오래된 창 메시지 차단, 타임아웃, 닫기 실패 후 재시도, 퇴장·초기화·종료 정리와 스탬프 저장 데이터 보존을 검증했습니다.

Chromium 모의 위젯에서 3·2·1 표시 간격과 한 번의 플래시, 자동 종료, 닫기·Esc, 모바일 터치 닫기, 모션 줄이기와 백그라운드 취소를 확인했습니다. 기존 PC 좌상단 창·맵 입력과 모바일 여러 화면 크기·접기/펼치기 10회 검증도 통과했습니다. 실제 ZEP 맵에서는 업데이트 후 포토존에서 F키로 연출을 실행하고 종료 후 이동·채팅 복귀 및 스탬프 창 복원을 확인하세요.
