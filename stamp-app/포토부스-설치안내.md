# POST:ME 내 아바타 폴라로이드 v1.11.1

## 다운로드 및 설치
전체 앱: https://github.com/junho3789/ZEP/raw/refs/heads/main/dist/zep-object-stamps-v1.11.1.zepapp.zip

기존 앱을 삭제하지 말고 전체 ZIP으로 업데이트한 뒤 맵에 재접속합니다. !stamp-version 확인값은 1.11.1-avatar-framing입니다. 기존 프로그램 이름·링크·구글폼·이벤트 ID·스탬프 ID와 오브젝트 설정을 유지했습니다. 같은 이벤트의 수집 기록을 이어갑니다.

ZIP 루트에는 main.js, stamp-ui.html, stamp-mini.html, stamp-special.html, stamp-entry.html, photo-booth.html 총 6개 파일이 있습니다. 특히 main.js와 photo-booth.html을 함께 업데이트해야 합니다.

## 오브젝트 연결
포토존 카메라 또는 단말기에 기존 스탬프와 같은 **ZEP Script 상호작용**을 설정합니다.

| 항목 | 설정 |
|---|---|
| 실행 방법 | F키 |
| 실행 범위 | 1 |
| 번호 | 206 |
| 값 | photo:booth |

v1.10에서 연결한 오브젝트라면 다시 설정하지 않아도 됩니다. 번호를 바꾸면 CONFIG.photoBooth.number/value와 맵 설정을 함께 바꿉니다. 스탬프 201~204·응모 데스크 205와 번호가 겹치면 안 됩니다.

## v1.11.1 표시 수정
- 원본 전체에서 상반신을 추출하며 아바타 확대 비율을 줄이고 머리 위·좌우·하단 여백을 확보합니다.
- 캐릭터 뒤 배경은 행사 연두색(#DFFF45) 단색입니다. 가로선과 파란 원을 제거했습니다.
- 흰색 폴라로이드 프레임 바깥의 초록·파랑 여백 및 미리보기 그림자를 제거했습니다.
- PNG 출력 크기는 바깥 여백을 뺀 832×1088입니다.

## 이용 흐름
1. F키로 포토부스를 엽니다.
2. **ZEP에서 제공한 player.avatarFileName + CDN 주소**로 현재 아바타를 불러옵니다. 사진 업로드나 수동 아바타 다운로드가 필요하지 않습니다.
3. 아바타 상반신, 현재 닉네임, NEW:TURN 로고, 행사 라임·블루 색상과 한국 시간 날짜로 폴라로이드를 만듭니다.
4. 이미지 준비가 끝나면 3 → 2 → 1 → 플래시를 표시하고 완성 카드를 보여줍니다.
5. PNG 저장 / 다시 만들기 / 닫기 중 선택합니다. 카드는 저장할 시간을 주기 위해 자동으로 닫지 않습니다.

PNG 크기는 832×1088입니다. PC는 다운로드 버튼을 사용합니다. 모바일은 지원되는 경우 파일 공유 메뉴를 열며, 공유 메뉴에서 이미지 저장을 선택할 수 있습니다. 파일 공유를 지원하지 않으면 다운로드를 시도합니다. 브라우저에서 직접 저장이 제한되면 표시된 이미지를 길게 눌러 저장하거나 PC의 이미지 저장 메뉴를 사용하세요.

다시 만들기를 누르면 아바타 파일명과 닉네임을 서버에서 새로 읽습니다. 저장 전까지 생성 이미지를 외부 서버로 업로드하지 않으며, 카드 이미지 자체를 player.storage에 저장하지 않습니다. 스탬프 수집 수·이동 속도·아바타 착용 설정도 바꾸지 않습니다. 연출과 결과 카드는 해당 이용자에게만 표시됩니다.

스탬프 창은 포토부스 이용 중 숨기고 닫은 뒤 원래 펼침/접힘 상태로 복원합니다. 반복 F 입력으로 카드를 중복 생성하지 않습니다. 닫기와 Esc를 지원하고 퇴장·앱 종료·관리자 초기화 시 정리합니다. 카운트다운 중 탭이 숨겨지면 취소하지만 결과 카드에서 파일 공유를 여는 것은 카드를 닫지 않습니다.

## ZEP 제공 아바타 이미지 경로
```js
var ZEP_AVATAR_IMAGE_BASE = 'https://cdn-static.zep.us/static/assets/baked-avartar-images/';
function getZepAvatarImage(player) {
  var fileName = player && player.avatarFileName;
  return typeof fileName === 'string' && fileName ? ZEP_AVATAR_IMAGE_BASE + fileName : '';
}
```

제공받은 경로의 **baked-avartar-images** 철자를 그대로 사용합니다. 다른 CDN이나 임의 캐릭터로 대체하지 않습니다. avatarFileName이 비어 있으면 아바타 꾸미기에서 저장한 뒤 다시 불러오도록 안내합니다.

## 원본 프레임 및 상반신 조절
CONFIG.photoBooth의 기본값입니다.
```js
CONFIG.photoBooth = {
  enabled: true, number: '206', value: 'photo:booth',
  stepMs: 1000, flashMs: 160,
  avatarFrame: { width: 0, height: 0, index: 0 },
  upperBodyRatio: 0.80
};
```

- stepMs: 숫자 표시 간격 500~2000ms. flashMs: 플래시 80~300ms.
- avatarFrame: 기본값 0×0은 CDN 원본 전체를 한 장의 이미지로 처리합니다. 큰 단일 아바타를 임의로 48×64로 잘라 머리만 표시하던 상황을 방지합니다.
- 실제 원본이 스프라이트 시트인 경우에만 프레임 width/height를 지정합니다. 원본 크기가 지정 폭·높이로 나누어지면 해당 프레임을 추출합니다. index는 0부터 시작해 왼쪽에서 오른쪽, 위에서 아래 순서입니다.
- 프레임의 투명 여백을 제거한 뒤 상단 upperBodyRatio 비율만 잘라 확대합니다. 0.45~0.95 범위이며 값을 늘리면 몸통이 더 많이 들어옵니다.

## 오류 안내
CDN 이미지는 crossOrigin='anonymous'로 읽습니다. Canvas PNG 저장에 필요한 CORS 응답을 허용해야 합니다. 이미지가 없거나 로딩·저장 권한이 실패하면 다른 캐릭터나 빈 카드로 대체하지 않고 오류 안내와 다시 불러오기·닫기를 표시합니다. 실제 원본이 예상과 다른 시트라면 위 avatarFrame 설정을 조정해야 합니다.

## 검증 및 적용 확인
Node 모의 ZEP 테스트 57개를 통과했습니다. CDN URL과 닉네임 전달, 결과 카드 유지, 최신 아바타 다시 읽기, 오래된 타임아웃 차단과 기존 관리자·수집·저장 기능을 포함합니다.

Chromium에서는 모의 CDN 이미지로 단일 프레임·스프라이트 시트 추출, 다리 영역 제외, 3·2·1과 플래시, 832×1088 PNG 다운로드, 다시 만들기, 파일명 누락·404·CORS 차단 안내, 모바일 파일 공유 분기와 터치, 다양한 화면 크기의 닫기 버튼을 확인합니다. 모의 캐릭터는 테스트 전용이며 앱 ZIP에는 포함되지 않습니다. 기존 PC 좌상단 UI/맵 이동과 모바일 접기·펼치기 테스트도 유지합니다.

이 실행 환경에서는 실제 ZEP CDN 파일을 가져오지 못했으므로 **실제 avatarFileName 제공, CDN CORS 응답과 프레임 형식은 맵 업데이트 후 확인해야 합니다.** 실제 맵에서 F키를 눌러 내 아바타와 닉네임이 나오고 PNG가 저장되는지 확인해 주세요. 잘못된 포즈나 여러 캐릭터가 보이면 원본 프레임 형식 확인이 필요합니다.
