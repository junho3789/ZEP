# NEW:TURN 뉴턴 스탬프 앱 · v1.5.2

## 달라진 UI
- 키비주얼의 형광 라임(#DFFF45), 블루(#0670FF), 블랙을 반영했습니다.
- 접기 버튼을 누르면 창을 제거하고 좌측 상단의 76×76px 영역에 뉴턴 아이콘만 표시합니다. 아이콘을 누르면 전체 창을 다시 엽니다.
- 아이콘에는 글자를 표시하지 않습니다. 마우스를 올리면 수집 개수가 보이고, 스크린리더에서도 수집 개수를 확인할 수 있습니다.
- 접힌 상태에서 오브젝트를 이용해도 스탬프는 저장되며, 펼치면 최신 기록을 표시합니다.
- 수집 전에는 옅은 뉴턴 실루엣, 수집 후에는 컬러 뉴턴 스탬프와 완료 표시가 나옵니다.
- 첨부 뉴턴 일러스트를 참조해 투명 배경의 스탬프용 PNG를 만들었습니다. 생성형 편집으로 준비한 이미지이므로 원본과 픽셀 단위로 동일한 파일은 아닙니다.
- 작은 화면에서 창 크기에 맞춰 전체 카드를 축소하며 내부 스크롤바를 만들지 않습니다.

## 설치 / 업데이트
다운로드: https://github.com/junho3789/ZEP/raw/refs/heads/main/dist/zep-object-stamps-v1.5.zepapp.zip

1. 기존 앱의 main.js에 입력해 둔 프로그램 링크 4개와 구글폼 링크, eventId, 오브젝트 id/번호/값을 새 CONFIG에 옮겨 주세요. 배포 ZIP의 링크는 빈칸입니다.
2. 기존 앱을 삭제하지 않고 업데이트해야 합니다. 동일 eventId와 오브젝트 id를 유지하면 저장 기록을 이어갑니다.
3. ZIP 최상위에 main.js, stamp-ui.html, stamp-mini.html이 있어야 합니다. 뉴턴 PNG는 두 HTML 내부에 직접 포함돼 있으므로 별도 이미지 파일은 필요하지 않습니다.
4. 이 폴더에서 python3 build.py를 실행하면 검사 후 ZIP을 만듭니다. 직접 압축하는 경우 위 3개 파일만 최상위에 넣으세요.
5. Normal app으로 맵에 적용하고 재접속합니다. !stamp-version에서 1.5.2-image-fix을 확인하세요.
6. 이번 변경은 main.js의 접기 위젯 전환도 포함하므로 HTML만 교체해서는 안 됩니다.

## 위치 / 크기 설정
- CONFIG.ui: 펼친 창의 위·오른쪽·아래·왼쪽 화면 대비 % 여백입니다.
- CONFIG.minimized: 접힌 창의 align(기본 topleft), width/height(기본 76px)를 바꿀 수 있습니다.
- 창이 작아지면 카드가 자동 축소됩니다. 아주 작은 펼침 영역에서는 헤더만 표시됩니다. 실제 ZEP 기본 앱 UI와 겹침은 맵에서 확인하세요.

## 오브젝트 연결
맵 편집기의 ZEP Script 상호작용을 사용하고 실행 방법은 F키, 실행 범위는 1로 시작합니다. 웹링크 열기 기본 동작을 중복 설정하지 마세요.

| 오브젝트 | 번호 | 값 |
|---|---|---|
| 프로그램 1 | 201 | stamp:1 |
| 프로그램 2 | 202 | stamp:2 |
| 프로그램 3 | 203 | stamp:3 |
| 프로그램 4 | 204 | stamp:4 |
| 안내데스크 | 205 | stamp:desk |

오브젝트에서 F키를 눌러 프로그램 링크를 ZEP 기본 팝업으로 열면 스탬프를 지급합니다. 실제 외부 페이지 로딩/프로그램 완료는 검증하지 않습니다. 동일 오브젝트는 중복 지급하지 않습니다. 기본 응모 기준은 4개이며 CONFIG.requiredStamps로 변경할 수 있습니다. 안내데스크에서 조건을 확인한 뒤 구글폼을 엽니다. 개인정보 수집 동의와 중복 제출 정책은 구글폼에서 설정하세요.

## 채팅 명령
- !stamps: 현황을 확인하고 전체 창을 다시 펼칩니다.
- !stamp-ui-hide: 창/아이콘을 숨깁니다. 저장 기록은 유지합니다.
- !stamp-version: 실행 버전 확인.
- !stamp-players: 관리자·맵 소유자만 현재 맵 접속자의 이름/ID 확인.
- !stamp-reset me: 관리자 본인 초기화 요청.
- !stamp-reset id 이용자ID: 해당 접속자 초기화 요청.
- !stamp-reset all: 요청 시점 현재 맵 접속자 전체 초기화 요청. 미접속자/다른 서버는 제외.
- !stamp-reset confirm: 30초 안에 요청을 확인하여 초기화.
- !stamp-reset cancel: 초기화 요청 취소.

관리자 role=3000, 맵 소유자 role=3001만 초기화할 수 있습니다. 현재 이벤트의 스탬프만 비우고 다른 저장 데이터는 보존합니다. 초기화 후 재수집할 수 있습니다. 실제 영구 저장은 같은 계정 재접속으로 확인하세요.

## 검증과 한계
JavaScript 스크립트 문법과 모의 ZEP 런타임에서 동작 테스트 27개를 확인했습니다. 기존 팝업/중복 방지/저장 오류 보호/관리자 초기화와 미니 아이콘 전환/접힌 상태 수집/펼침 시 기록 유지/채팅으로 펼치기를 포함합니다.
작업 환경의 시작 지연으로 현재 브라우저와 실제 ZEP에서 새 디자인을 직접 실행 검증하지는 못했습니다. 맵에 적용한 뒤 접기/펼치기, 이미지 표시, 작은 창과 모바일, 기본 UI와의 겹침, 링크 팝업을 닫은 후 이동, 재접속 저장을 확인하세요.


## v1.5.2 접기 오류 수정
destroy()가 false를 반환했다는 이유만으로 UI 전환을 막던 코드를 수정했습니다. 실제 예외가 나지 않으면 핸들을 정리하고 뉴턴 미니 아이콘으로 전환합니다. 실제 예외가 나면 기존 접기 상태로 되돌려 다음 클릭으로 재시도할 수 있습니다.
false 반환 조건에서 접기/펼치기 8회 반복, 스탬프 기록 보존, 지연 메시지 차단, 제거 예외 후 재시도를 모의 런타임에서 확인했습니다. 실제 ZEP 검증은 업데이트 후 필요합니다.
이번 패치는 main.js만 변경하면 됩니다. 기존 v1.5의 stamp-ui.html, stamp-mini.html, newton-stamp.png는 그대로 유지합니다. 전체 ZIP으로 업데이트할 때는 기존 링크와 CONFIG 설정을 새 main.js에 옮겨 주세요.


## v1.5.2 이미지 미표시 수정
기존 HTML은 newton-stamp.png라는 상대 경로를 사용했습니다. ZEP 위젯 문서에서 이 상대 경로를 찾지 못하면 이미지가 깨집니다. 펼친 창과 미니 아이콘 모두 PNG 바이트를 data:image/png;base64 형식으로 HTML에 직접 포함하도록 수정했습니다. 외부 이미지 URL이나 상대 경로 해석에 의존하지 않습니다. 뉴턴 일러스트 자체는 이번 패치에서 바꾸지 않았습니다.

기존 v1.5.1 앱을 유지하며 수정하려면 새 ZIP에서 stamp-ui.html과 stamp-mini.html만 기존 ZIP에 교체하면 됩니다. main.js와 운영 링크/이벤트/오브젝트 설정을 그대로 유지할 수 있습니다. 이 경우 버전 명령은 이전 버전으로 표시됩니다. 전체 ZIP을 적용할 때는 새 main.js의 CONFIG에 기존 링크와 설정을 옮기고, 동일 앱을 업데이트한 뒤 재접속하세요. !stamp-version의 새 버전은 1.5.2-image-fix입니다.

모의 런타임 테스트 27개, 두 위젯 스크립트 문법, 두 HTML의 동일 PNG 포함 및 상대 이미지 경로 제거를 확인했습니다. 실제 브라우저/ZEP 실행 환경은 현재 사용할 수 없어 실제 표시 확인은 업데이트 후 필요합니다.
