# NEW:TURN 스탬프 앱 v1.7.1 · 뉴턴 스페셜 카드

## 이번 동작
1. 프로그램 1~3 오브젝트에서 F키: 기존처럼 웹링크 팝업 열기와 스탬프 수집.
2. 프로그램 4 오브젝트에서 F키: **링크 없이** 스페셜 카드 팝업 표시와 4번 스탬프 수집.
3. 카드 상단에 **뉴턴을 찾았습니다.** 문구 표시.
4. 카드 닫기 또는 Escape: 카드만 닫기. 별도 showAlert 발견 알림은 표시하지 않음.
5. 스탬프 조건을 충족한 뒤 안내데스크에서 F키: 기존 구글폼 응모 링크 열기.

4번을 다시 이용하면 카드를 다시 볼 수 있지만 스탬프는 중복 지급하지 않습니다. 카드 창이 이미 열려 있으면 추가 창을 만들지 않습니다. 저장 실패 시 카드를 닫고 실패를 안내합니다. 관리자 초기화/퇴장/앱 종료 시에도 별도 발견 알림 없이 카드를 정리합니다.

## 카드 디자인
희귀 수집 카드 분위기의 SSR 프레임, 라임·블루·블랙 기본색과 홀로그램 질감, 움직이는 반사광, 카드 주변 회전 광원과 별빛을 사용합니다. 특정 카드게임의 로고나 카드 도안은 사용하지 않았습니다. 실제 확률 추첨/결제 기능은 없습니다.

캐릭터는 사용자가 제공한 018.zip 안의 018.png 원본(53×62 RGBA)을 그대로 사용합니다. 재생성/재인코딩하지 않고 원본 PNG 바이트를 HTML에 포함하며, CSS로 표시 크기만 조절합니다. 원본은 stamp-four.png로 보관하고 바이트 일치 테스트를 합니다. 1~3번 스탬프, 스탬프 수집 창의 4번 그림, 미니 아이콘은 이전 버전을 유지합니다.

프레임/홀로그램/회전 광원은 UI 레이어로 구성했습니다. 운영체제/브라우저의 동작 줄이기 설정에서는 애니메이션을 정지합니다.

## 수집 UI와 관리자 명령
수집 UI는 라임/블루 NEW:TURN 디자인입니다. 접으면 좌측 상단에 뉴턴 아이콘만 남고 누르면 다시 펼쳐집니다. 작은 화면에서는 영역에 맞춰 축소하며 내부 스크롤바를 만들지 않습니다.

- !stamps: 현황 확인 및 수집 창 펼치기.
- !stamp-ui-hide: 수집 창/아이콘 숨기기. 스탬프 기록은 유지.
- !stamp-version: 현재 앱 버전 확인.
- !stamp-players: 현재 맵 접속자 이름/ID 조회. 관리자/맵 소유자만 가능.
- !stamp-reset me: 관리자 본인의 현재 이벤트 스탬프 초기화 요청.
- !stamp-reset id 이용자ID: 지정 접속자 초기화 요청.
- !stamp-reset all: 요청 당시 현재 맵 접속자 전체 초기화 요청. 미접속자/다른 맵·서버는 제외.
- !stamp-reset confirm: 30초 안에 입력해 초기화 적용.
- !stamp-reset cancel: 초기화 취소.

관리자 role=3000, 맵 소유자 role=3001만 초기화할 수 있습니다. 다른 저장 필드는 보존합니다. 같은 계정 재접속으로 실제 영구 저장도 확인하세요.
